# Mella MVP

## Run
1. Install Node.js 20.9+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

The current build is UI-only: homepage, navigation, featured auction, live auction cards, how-it-works and trust sections. Backend, authentication, demo bidding, MongoDB and Telebirr will be added next.
